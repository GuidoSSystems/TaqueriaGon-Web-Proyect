# Taqueria Gon Web Project

Taqueria Gon Web Project is a web-based Point of Sale (POS) system designed for a taqueria business. It combines a backend API and a front-end web interface to support daily restaurant operations such as sales, inventory, kitchen tracking, tables, finances, and user authentication.

This repository contains the application source code, configuration files, database setup, and supporting project documentation for the Taqueria Gon system.

## Project overview

The system is structured as a TypeScript + Express application with static HTML pages for the user interface. It is intended to help staff manage:

- sales and POS operations
- table and order workflow
- inventory records
- kitchen preparation status
- financial overview
- employee login and access control
- local development environment with Docker and MySQL

## Key features

- POS-style sales interface
- login and protected routes
- inventory management pages
- kitchen workflow pages
- tables and order screens
- finance dashboard
- MySQL database integration
- Dockerized local environment
- TypeScript-based backend architecture

# Getting Started

A comprehensive guide to set up, build, and run the project locally in both development and production environments.

---

## Prerequisites

Ensure you have the following tools installed on your system before proceeding:

- **Node.js**: Version 18.0.0 or higher
- **npm**: Default package manager included with Node.js
- **Docker & Docker Compose**: Recommended for local database provisioning
- **MySQL**: Required only if you are not using Docker to run the database

---

## Installation & Setup

### 1. Install Dependencies

Install the required packages defined in `package.json`:

```bash
npm install
```

### 2. Configure Environment Variables

Create your local configuration file from the provided example template:

```bash
cp .env.example .env
```

After copying, open `.env` and update the database credentials, application ports, and any environment-specific secrets.

### 3. Start the Database

Launch the MySQL container in detached mode using Docker Compose:

```bash
docker-compose up -d
```

---

## Running the Application

### Development Mode

Run the application with hot-reloading enabled for TypeScript files:

```bash
npm run dev
```

### Production Build

To compile TypeScript and start the compiled application:

1. Compile the source code:
   ```bash
   npm run build
   ```

2. Start the production server:
   ```bash
   npm start
   ```

---

## Available Scripts

The following scripts are defined in `package.json`:

| Script | Command | Description |
| :--- | :--- | :--- |
| `npm run dev` | `nodemon --watch src --ext ts --exec tsx src/app.ts` | Runs the development server with live reload on file changes. |
| `npm run build` | `tsc` | Compiles TypeScript source files into JavaScript inside `dist/`. |
| `npm start` | `node dist/app.js` | Executes the compiled production entry point. |
| `npm test` | `echo "Error: no test specified" && exit 1` | Placeholder for automated test suites. |
